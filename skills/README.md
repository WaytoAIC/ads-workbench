# 广告经营技能包

十个 skill 加一份共享口径，和「广告周检本地工作台」绑定使用。装进 Claude Code、Codex 或 Hermes 之后，Agent 知道每一步读工作台的哪个文件、判断什么、写到哪、哪些事必须留给人。

一句话：**数字归脚本，判断归模型，拍板归人。**

## 和旧版九个广告 skill 的区别

- **从广告优化到经营。** 顺序是：先算账定目标 → 再拆指标找限制 → 再判断每条广告的任务 → 再选路径 → 最后才是出价和否词。
- **和工作台绑定。** 每个 skill 写明读哪个文件的哪个键、对应页面的哪一页。动作一律进「行动 · 待你决定」，等人逐条审批。
- **新品和成熟链接分开。** `ads-launch` 管新品期，其余默认面对成熟链接，入口按阶段分流。
- **枚举写死。** 任务六类、搜索词七类、路径四条、核心限制七类，输出只能从集合里选。
- **阈值只有一份。** 所有阈值和调幅都在仓根 `口径.json`，技能包只引用键名。
- **每条建议带出处和下一步。** 标「可执行 / 缺什么才能执行」，并回答三问：为什么做、预期改变什么、多久复盘。

## 十个 skill 各管什么

| skill | 管什么 | 主要读 | 对应页面 |
|---|---|---|---|
| `ads-router` | 入口。看工作台状态和产品阶段，选 1 到 3 个专用 skill | `参数.json`、`广告闭环/输出/数字.json`、`广告闭环/输出/经营.json`、`运行记录/runs.jsonl` | 首页 |
| `ads-profit-target` | 算账定目标：定价毛利率 → 目标 TACOS → 单品日预算 → 阶段要求 | `广告闭环/输出/经营.json` 的 `算账` | 首页、设置 |
| `ads-diagnose` | 拆指标找限制，只输出一个核心限制 | `广告闭环/输出/经营.json` 的 `拆解` | 原因 |
| `ads-campaign-task` | 每个活动的任务与完成情况；纯利型广告；结构体检 | `广告闭环/输出/经营.json` 的 `任务` | 广告活动 |
| `ads-search-term` | 搜索词分七类、收割、否定、竞品词分拣、相斥词根 | `分组规则.json`、分组明细、否词清单 | 行动、原因 |
| `ads-bid-budget` | CPC 天花板、分档调幅、调价节奏、预算、广告位 | `广告闭环/输出/动作清单.json`、`广告闭环/输出/竞价调整表.csv` | 行动、广告活动 |
| `ads-path-decision` | 四条利润路径选一条，九栏决策表，三问 | `广告闭环/输出/经营.json` 的 `路径`、`决策表` | 原因、设置 |
| `ads-weekly-review` | 每周一圈、等长窗口复盘、周报草稿 | `运行记录/runs.jsonl`、`广告闭环/输出/读回状态.json` | Agent 运行、首页 |
| `ads-launch` | 新品期：五阶段、节奏、六项体检、库存、词库分层 | `广告闭环/输出/数字.json` 的 `逐周`、`库存` | 设置、首页 |
| `ads-variant-season` | 规格分工与内耗；淡旺季的目标、预算、出价 | `广告闭环/输出/数字.json` 的 `库存`、`广告闭环/输出/广告产品调整表.csv` | 广告活动、设置 |

共享口径在 `ads-shared/`（不是技能，没有 SKILL.md）：

| 文件 | 内容 |
|---|---|
| `ads-shared/分工与红线.md` | 三方分工、字段分工表、Agent 不做的事、缺数据写缺 |
| `ads-shared/公式与口径.md` | 全部公式；`口径.json` 每个键的含义和谁在用 |
| `ads-shared/输出格式.md` | 四栏表、动作表、三问、九栏决策表、落盘规则 |
| `ads-shared/术语.md` | 指标、五组枚举、动作类型归谁解释、状态词 |

每个 skill 目录三样：`SKILL.md`（何时用、读什么、判断步骤、输出、不许做的、自查）、`references/规则.md`（细则）、`templates/输出.md`（输出模板）。同一条规则只写在一处，别处引用。

## 和工作台怎么配合

```text
人在「设置」页定目标和取舍项
        │
脚本跑一圈 ──→ 数字.json、经营.json、动作清单.json、验证器.json     （数字归脚本）
        │
技能包读这些产物 ──→ 对话里回答；每周一圈时写 AI补位.json            （判断归模型）
        │
人在「行动」页逐条通过或驳回，在「广告活动」页确认任务，点了才发群    （拍板归人）
        │
到复盘日，读回上一圈，再转一圈
```

- 接口契约见 `docs/架构.md`：技能读哪些文件、谁写哪些字段、枚举集合。技能包照它写；契约改了，先改 `ads-shared/`，再改受影响的 skill。
- 技能包不碰广告后台，不写状态库 `工作台.db`，不改 `广告闭环/输出/` 下的任何文件。
- 平时被问到只回答；只有每周一圈（`_脚本/weekly.py`）会经 `_脚本/llm.py` 校验后落盘到 `广告闭环/输出/AI补位.json`。
- 工作台还没跑过时，技能不分析，会让你先在首页点「跑一圈」，或运行 `python3 _脚本/weekly.py --dry-run`。换成自己的数据见 `数据格式.md`。
- 改了技能包或换了模型，用 `评测/` 下的考卷跑一遍（`_脚本/eval.py`）。

## 怎么装

```bash
cd skills
./install.sh --target claude --dry-run     # 先看会拷什么
./install.sh --target claude               # 装到 Claude Code
./install.sh --target codex                # 装到 Codex
./install.sh --target hermes --profile ads-agent   # 装到 Hermes 的某个 profile
```

- 一次拷 11 个目录：`ads-shared` 加十个 skill。
- 目标位置已有同名目录：整体挪到和 skills 根目录并排的备份目录（skills 根目录名后面加 `.bak-<时间戳>`），再拷新的。不删除任何文件；备份放在根目录外面，旧版不会被当成重复的技能加载。
- `--dest 目录` 可以直接指定装到哪，优先于 `--target`。
- 装完从 `ads-router` 开始用；也可以直接说出某个 skill 管的事。
- 装进 Hermes 的完整步骤（人设、技能包、每周定时）用 `agent/install_hermes.sh`，它会调用这里的 `install.sh`，说明见 `agent/README.md`。

用的时候让 Agent 的工作目录在工作台的数据目录（仓根，或 `python3 工作台/app.py --root <目录>` 的那个目录），技能里写的路径都是相对这个目录的。

## 怎么改

| 想改什么 | 改哪里 |
|---|---|
| 某个阈值、调幅 | 仓根 `口径.json`。技能包里没有第二份数字 |
| 某个键的名字 | `口径.json`，然后同步 `ads-shared/公式与口径.md` 第八、九节和引用它的 skill |
| 只有技能用、值还是暂定的阈值 | 列在 `ads-shared/公式与口径.md` 第九节；直接改 `口径.json` 里的值，流水线不受影响 |
| 品类词表、七类标签的文字 | `分组规则.json` |
| 某条判断规则 | 对应 skill 的 `references/规则.md` |
| 输出长什么样 | `ads-shared/输出格式.md`，或对应 skill 的 `templates/输出.md` |
| 触发话术 | 对应 `SKILL.md` 的 frontmatter `description`（它是唯一的触发依据） |
| 枚举集合 | 先改 `docs/架构.md` 和校验脚本，再改 `ads-shared/术语.md` |

## 方法来源

经营框架参考了两场行业分享，规则与阈值为本仓自定。出价、否词与复盘的若干口径参考了公开资料中的通行做法，均用自己的话重写，并改为从 `口径.json` 取值。

技能包不含任何真实店铺的数据。示例数字都是演算用的假设值。
