# 术语

技能包里反复出现的词，在这里各说一次。枚举都是写死的集合：输出时只能从集合里选，选不出来就用集合里表示「不确定」的那一项。

## 一、指标与口径

| 词 | 意思 |
|---|---|
| 定价毛利率 | 不含广告费的利润空间。和「广告后利润率」不是一回事 |
| TACOS | 广告花费 ÷ 总销售额。回答「广告吃掉了多少销售额」 |
| ACOS | 广告花费 ÷ 广告销售额。回答「广告买单的效率」 |
| 广告销售额占比 | 广告带来的销售额占总销售额多少。没有单独的健康线，要和 ACOS、目标 TACOS 放在一起看 |
| 盈亏线 | TACOS 或 ACOS 到这个数，这一单就不赚不赔。等于定价毛利率 |
| 目标 ACOS | 人在 `参数.json` 里定的广告效率目标，出价规则用它 |
| 目标 TACOS | 定价毛利率减去目标广告后利润率，预算边界用它 |
| 单品日预算 | 一个产品全部活动一天合计能花多少。按销售额和目标 TACOS 算出来的边界 |
| 获单成本 | 买一个广告订单花多少钱 |
| 归因未满 | 最近几天的订单还没全部记到广告名下，这几天的转化看起来会偏低 |
| 窗口 | 用来比较的两段等长日期，工作台里叫「窗口前」「窗口近」 |
| 父体、子体 | 一个链接和它下面的各个规格。经营核算以父体为单位 |

## 二、五组枚举

### 广告任务（六类）

| 值 | 这条广告在干什么 | 是手段还是目的 |
|---|---|---|
| 纯利型 | 直接买有利润的订单。按最保守算法（新增广告一个自然单都不带）ACOS 仍不高于目标 TACOS，并且有成交规模 | 目的 |
| 推自然位 | 暂时接受较高成本，换某个词的自然排名 | 手段 |
| 测词拓词 | 花小钱找新的可成交词、新的流量入口 | 手段 |
| 收割 | 把已经验证能成交的词收进精确组单独出价 | 目的 |
| 防守 | 守自家品牌词和自家商品页，不让别人截走 | 目的 |
| 未判定 | 证据不够，或人还没确认 | — |

### 任务完成情况（三类）

`达标`、`未达标`、`看不出`。缺判断所需的数据（例如没有自然排名）一律是「看不出」。人在页面确认过的任务，在 `任务` 里记作 `人定任务`，完成情况按人定的判。

### 搜索词分组（七类）

标签的文字因品类而异，**读 `分组规则.json` 的 `标签`**，不要背示例里的写法。七个槽位的含义固定：

| 槽位 | 含义 |
|---|---|
| `0` | 自家品牌词 |
| `1` | 核心大词：就是这个品的名字，不带修饰 |
| `2` | 属性长尾：核心词加规格、材质、功能、人群等修饰 |
| `3` | 竞品品牌词 |
| `41` | 跑偏：买家要的是另一种东西 |
| `42` | 泛词：品类沾边，但不是这个品的使用场景 |
| `5` | ASIN 投放：搜索词一栏是别家商品编号 |

### 利润路径（四条）

| key | 名称 | 一句话 |
|---|---|---|
| `增单` | 价格与 TACOS 不变，把订单做大 | 利润率不动，靠量 |
| `降耗` | 订单稳住，减少广告对利润的消耗 | 量不动，靠 TACOS 降 |
| `调价` | 调整售价 | 量和广告效率都难动时，动价格 |
| `重构` | 重新设计价格、广告、利润三者的关系 | 当前的赚钱方式不成立，换一种 |

脚本的 `路径.脚本建议` 还可能是「先解决库存」：那不是第五条路径，是说现在选哪条都得先过库存这一关。

### 核心限制（七类）

`库存`、`CPC`、`CVR`、`广告销售额占比`、`无效广告`、`利润空间`、`无明显限制`。一次只输出一个。

### 另外三个小集合

- 算账判定：`在目标内`、`超出目标`、`已亏损`。
- 归因入口：`利润率差`、`单量低于预期`、`销量超预期`。
- 产品阶段（`参数.json` 的 `产品阶段`）：`新品期`、`放量期`、`维稳期`、`盈利期`。旧写法 `成长期` 按放量期读，`成熟期` 按维稳期读。

## 三、路径和取舍项不是一回事

- **路径**是经营方向，四选一，回答「这个链接接下来靠什么多赚钱」。
- **取舍项**是这一圈让脚本出哪几组动作，在「设置」页勾选，回答「这一周先动哪几类」。现有五组，定义在 `广告闭环/输出/选项.json`：保主力规格、结构去重、竞品品牌词分拣、只做粗规则否词、先查退款和到仓。

人先选路径，再看哪些取舍项服务这条路径。没勾的取舍项，脚本不出对应动作，这不算漏。

## 四、动作类型归谁解释

工作台的动作类型用原名。被问到某一类动作「为什么出」「要不要过」时，按下表找 skill。

| 动作类型 | 归哪个 skill |
|---|---|
| 暂停广告产品、补挂广告产品 | ads-launch（新品）、ads-variant-season（变体分工） |
| 下调预算、预算上调 | ads-bid-budget |
| 降竞价（结构压价）、关键词降竞价、关键词提竞价、暂停关键词 | ads-bid-budget |
| ASIN 定位、类目定位、自动投放组的降竞价、提竞价、暂停或关闭 | ads-bid-budget |
| 改竞价策略、下调默认竞价 | ads-bid-budget |
| 广告位待补数据 | ads-bid-budget |
| 下调广告位加价／上调广告位加价 | ads-bid-budget |
| 换道否定、搜索词收割、来源组否定 | ads-search-term |
| 竞品词降价单独跑、竞品词否定、否定 ASIN、粗规则否词 | ads-search-term |
| 交回运营判断 | ads-search-term（否词没否干净）、ads-campaign-task（有意为之的结构） |
| Listing 建议稿、查证 | ads-diagnose |

## 五、工作台的状态词

| 词 | 意思 |
|---|---|
| 待处理、待重跑 | 输入变了（目标、到仓周数、取舍项或数据），要再跑一圈 |
| 待核对 | 这一圈跑完了，等人处理动作 |
| 遇到问题 | 缺输入或验证器没过，这一圈没出结果，上一份有效结果不动 |
| 待确认 | 一条动作的初始状态，等人通过或驳回 |
| 已确认（页面上叫通过）、驳回、已执行、已验证、已作废 | 人处理后的状态；驳回必须有理由；已执行是人去后台做完回来标的；输入变了、没人点过的旧动作会作废 |
| 复盘日 | 下一次回头看效果的日期，在 `参数.json` 里 |
