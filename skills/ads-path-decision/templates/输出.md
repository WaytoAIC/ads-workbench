## 决策表

| 栏 | 内容 | 谁写 |
|---|---|---|
| 当前状态 | 〔阶段、季节属性、销量、售价、定价毛利率、TACOS、ACOS、广告销售额占比〕 | 脚本 |
| 首要目标 | 〔人的原话 /（待你定）〕 | 人 |
| 核心限制 | | 脚本，我解释 |
| 选择方向 | 〔路径 + 抓手〕 | 我建议，人选 |
| 执行方案 | 〔具体到词、规格、活动、价格或预算；引用动作编号〕 | 我起草 |
| 投入边界 | 〔预算上限、动哪些不动哪些、能承受的阶段损失（待确认）〕 | 我起草，人确认 |
| 验证标准 | 〔哪个数变成什么样算有效；样本要求〕 | 我起草 |
| 复盘时间 | 〔初查日、决定日；本轮复盘日〕 | 脚本出骨架，我细化 |
| 后续选择 | 〔有效怎么放大；无效怎么撤回；撤回后换哪条〕 | 我起草 |

人没定首要目标时，最多再给一张「如果目标是另一种」的简表，只写和上表不同的栏。
