# ads-diagnose · 规则

公式见 `../ads-shared/公式与口径.md` 第三节（路径都从本 skill 目录算起）。

## 一、六个节点怎么读

| 节点 | 偏高或上升说明 | 先排除 |
|---|---|---|
| TACOS | 广告吃掉的销售额比例变大 | 总销售额因断货、退款、促销结束而下降 |
| ACOS（全部广告） | 买广告订单变贵 | 归因未满；品牌广告和视频广告口径较宽，和商品推广混在一起看会失真 |
| 广告销售额占比 | 生意更依赖广告 | 归因口径宽造成的虚高；自然单因断货下降 |
| CPC | 每次点击更贵 | 花费结构变了（更多钱去了贵的活动），而不是每个词都变贵 |
| CVR | 这个节点是「偏低或下降」才是问题：点击接不住 | 归因未满；买的词变了；主力规格断货 |
| 客单价 | 这个节点升降都要解释 | 促销、调价、规格结构变化 |

读节点的三条规矩：

1. 先看「变化」，再看「水平」。上周到这周动了多少，和相对目标高了多少，是两件事。变化问题找最近的改动；水平问题找长期结构。
2. 比例的变化用「个点」说，不用百分比的百分比。
3. 脚本给的 `判定` 是「正常、偏高、偏低」之一，原样引用。

## 二、三条归因路径

每一步都是一个二选一。哪一步没有数据，就停在那里写「看不出」。

**入口一：销量超预期**

1. 市场整体在涨，还是只有自己在涨？（要市场搜索量或类目销量；没有就看不出）
2. 是转化变好，还是流量变多？（`逐周` 的 CVR 和点击）
3. 多出来的是自然单，还是广告单？（广告销售额占比的变化）
4. 定位到哪个动作或哪个事件带来的（读回状态里上一圈执行了什么、有没有促销）
5. 结论要回答：这个增长能不能留住，要不要跟着加预算（回 `ads-profit-target` 重算边界）

**入口二：单量低于预期**

1. 市场在跌，还是自己没达标？
2. 是转化掉了，还是流量少了？
3. 少的是广告流量，还是自然流量？
4. 广告流量少：是词不够（覆盖的搜索词少），还是位置不够（有词但出价低、曝光少）？
5. 对应三种补法：加词、加竞价、加预算。到底补哪种，交给 `ads-search-term` 和 `ads-bid-budget`

**入口三：利润率差**

1. 哪一块费用高了？（广告费、折扣、仓储、退款；本 skill 只有广告费和退款率的数，其余写缺）
2. 广告这块：是获单成本高，还是广告订单占比高？
3. 获单成本高：是转化低，还是 CPC 高？
4. 再往下：是竞品有动作（降价、抢位），还是自身竞争力的问题（价格、评价、图片）？
5. 竞争力的问题不是广告能解决的，结论里直说，并指向 Listing 和价格

## 三、核心限制的判定顺序

脚本按下面的固定顺序判，命中第一条即停，并把命中的那条规则原文写在 `拆解.核心限制.规则`。你解释时照这个顺序说，不另排一套。

| 顺序 | 条件 | 判成 | 用到的口径 |
|---|---|---|---|
| 一 | 库存撑不到补货到仓（异常里「库存够卖几周」亮了） | `库存` | — |
| 二 | TACOS 高过定价毛利率 | `利润空间` | — |
| 三 | TACOS 超目标，ACOS 也高于目标 ACOS：CPC 环比涨幅过线判 `CPC`；否则转化率环比下滑过线判 `CVR`；都没过线，取环比更不利的那个 | `CPC` 或 `CVR` | `经营.CPC环比涨幅警戒`、`经营.CVR环比下滑警戒` |
| 四 | TACOS 超目标，但 ACOS 不高于目标 ACOS | `广告销售额占比` | — |
| 五 | 有活动 ACOS 超盈亏线，且它的花费占全部活动花费过线 | `无效广告` | `经营.无效广告花费占比警戒` |
| 六 | 以上都不命中 | `无明显限制` | — |

读这张表要知道的三件事：

- 货的问题压过一切；账本身亏了（第二条）压过效率问题。
- 第三条里 CPC 和 CVR 是按环比判的。两个都没过线时选的是「更不利的那个」，这种情况证据偏弱，在「AI 判断」里说明。
- 第五条只在 TACOS 没超目标时才轮得到。TACOS 超了目标、同时又有成规模的无效广告时，脚本报的是 CPC、CVR 或广告销售额占比，无效广告要写进「同时看到的」。

你可以有不同看法的典型情形：脚本按环比报了 CPC，但你看到泛词花费占比在升、转化率在几周里缓慢下降；或脚本报了广告销售额占比，但任务盘点里有大块未达标的花费。看法写进「AI 判断」，带证据和验证办法，脚本的结论不动。

## 四、交棒表

| 核心限制 | 下一个 skill | 让它回答 |
|---|---|---|
| 库存 | 新品 → ads-launch；多规格 → ads-variant-season；否则 ads-bid-budget | 断货规格上的广告先收哪些、预算降多少 |
| 利润空间 | ads-profit-target → ads-path-decision | 目标是否定得合理；要不要走调价或重构 |
| CVR | ads-search-term（是不是买错了词）；Listing 的问题指到「Listing 建议稿」 | 哪类词在拉低转化；页面要改什么 |
| CPC | ads-bid-budget | 哪些对象超过了天花板、按什么节奏降 |
| 无效广告 | ads-campaign-task | 哪些活动的任务没完成、该撤回还是转移预算 |
| 广告销售额占比 | ads-campaign-task → ads-path-decision | 广告是手段还是目的；自然单从哪补 |
| 无明显限制 | ads-path-decision | 有余量时往哪条路走 |

## 五、转化问题还是出价问题

这是最容易判错的一步，错了动作就反了。

| 现象 | 多半是 | 不要做 |
|---|---|---|
| 点击率低、ACOS 高 | Listing（主图、标题、价格、评价数）吸引不了点击 | 加竞价抢位 |
| 点击率正常、转化率低、买的词没变 | 页面承接（价格、评价、规格缺货、描述不符） | 降竞价了事 |
| 转化率低、泛词和跑偏词花费占比上升 | 买错了词 | 改 Listing |
| 转化率稳、CPC 上升 | 出价高了或竞争加剧 | 否词 |
| CPC 稳、转化率稳、ACOS 仍高于目标 | 目标定得比这个品的实际能力低，或客单价太低 | 继续微调出价 |
| 退款率连续上升（超过 `判定.退款率警戒`） | 产品或描述的问题，会滞后拖累转化 | 只看广告报表 |

## 六、分层时每一层看什么

| 层 | 取数 | 这一层能回答 | 常见的缺 |
|---|---|---|---|
| 目标 | `算账` | 高是相对谁高 | 定价毛利率没确认 |
| 父体整体 | `四周`、`逐周` | 是这周的事还是一直如此 | 周数少 |
| 活动 | `活动表` 两个窗口 | 是不是集中在少数几个活动 | 没有活动报告时由搜索词报告聚合，`口径核对` 会标 |
| 广告组或投放 | 关键词、定位的表现（脚本在动作依据里用到） | 是哪些词、哪些定位 | 没给关键词竞价表、商品定位表 |
| 搜索词 | `分组账-近14天`、分组明细 | 是哪一类词 | 分组可能分错，要人纠错 |
| 广告位 | 广告位报表 | 钱花在搜索顶部、其余位置还是商品页 | 多数时候没有这张表 |
| 时段 | 分时段数据 | 是不是某些时段在空烧 | 工作台目前不读这类数据 |

走到「缺」的那层就停，把上一层的结论作为定位结果，并写「再往下要补某某」。

## 七、样本与时间的提醒

- 两个窗口都要去掉归因未满的那几天再比；脚本没去掉时，你在结论里标出来。
- 新品头两周、件数很少的周，单周波动不作数，看两周合计。
- 大促、清仓、Deal 所在的周，转化和客单价都不正常，不拿来当基准。
- 上一圈刚做过大改动（`复盘.大改冷静期天数` 之内）：变化里有一部分是改动本身造成的，先说这一点。
