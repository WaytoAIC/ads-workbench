# ads-search-term · 规则

阈值都引用 `口径.json` 的键，含义见 `../ads-shared/公式与口径.md` 第八、九节；公式见同一文件第五节（路径都从本 skill 目录算起）。

## 一、七类怎么认

标签的文字读 `分组规则.json` 的 `标签`。下面按槽位说判断方法，括号里是脚本用到的词表。

| 槽位 | 含义 | 怎么认 | 容易错在哪 |
|---|---|---|---|
| `5` | ASIN 投放 | 搜索词一栏就是一个商品编号 | 不要把带数字的规格词当成编号 |
| `0` | 自家品牌词 | 含自家品牌名（读产品信息里的品牌） | 品牌名是常用词时容易误中；拼写变体会漏 |
| `3` | 竞品品牌词 | 含别家品牌名（`COMP`） | 新冒出来的品牌词表里没有，会被分到别的类；这是最常需要补位的一类 |
| `41` | 跑偏 | 买家要的是另一种东西（`OFF`） | 和泛词的区别：跑偏是「不是这个品」，泛词是「是这个品类但不是这个用途」 |
| `42` | 泛词 | 没有这个品的购买意图词根（不含 `INTENT`） | 意图词根列得太少，会把好词误判成泛词 |
| `1` | 核心大词 | 就是品名（`CORE`），不带任何修饰（不含 `MOD`） | 语序不同的变体都算核心词 |
| `2` | 属性长尾 | 有购买意图，带了规格、材质、功能、人群等修饰 | 其余都落在这里，所以这一类里可能藏着分错的词 |

脚本的判断顺序就是表里从上到下的顺序，前面命中就不往后看。

补位时的读法：

1. 先问「搜这句话的人，想买的是不是这个品」。不是 → 跑偏。
2. 是这个品类，但场景、人群、用途对不上 → 泛词。
3. 里面有品牌名：自家的 → `0`；别家的 → `3`。品牌名不认识、但格式像品牌（专有名词、非常规拼写）→ 归 `3` 并在理由里写「疑似品牌，请确认」。
4. 剩下的：只有品名 → `1`；品名加修饰 → `2`。
5. 两类都说得通时选更保守的那个（更不容易被否的那个）。
6. 拿不准就不写，让它留在兜底分组；落盘的格式里没有理由栏，理由只在对话里说。

## 二、否定的三道闸

一个词要同时过三道闸才写「够否」。脚本出否定动作时用的是固定点击门槛和偶然概率；样本闸里的动态门槛是你复核时加的。

| 闸 | 条件 | 没过时怎么写 |
|---|---|---|
| 样本闸 | 点击数 ≥ 动态门槛。动态门槛 ＝ `门槛.粗规则否词点击` 与 floor（1 ÷ 账户转化率）中较大的一个。账户转化率取 `SP-近14天.CVR` | 「观察：现在几次点击，门槛是几次」 |
| 偶然闸 | （1 − 基准转化率）^点击数 ≤ `判定.竞品词否定的偶然概率上限` | 「观察：零单纯属偶然的概率还有多少」 |
| 历史闸 | 在全部数据窗口里从没出过单 | 「出过单，不否；看是不是该降价」 |

再加三条底线（验证器会查，不过整轮作废）：

- 否词清单里没有自家品牌词。
- 没有出过单的词。
- 没有重复否定已经否过的词。

为什么门槛要跟着转化率走：转化率是一成的产品，十次点击不出单很常见；转化率是三成的产品，十次点击不出单就很说明问题。写死一个点击数，对前者会误杀，对后者又太慢。

读 `回测` 的方法：它站在前一个窗口的末尾，用几个不同的点击门槛去标零单的词，再看这些词在后一个窗口有没有出单。「当时会标的词」里「后来出单的词」占比高，说明这个门槛对这个产品太松。把这个比例告诉人，比任何一句「谨慎否词」都有用。

## 三、精确否定还是词组否定

| | 精确否定 | 词组否定 |
|---|---|---|
| 挡住什么 | 只挡这一个搜索词 | 所有包含这个词根的搜索词，包括还没出现的 |
| 什么时候用 | 默认 | 同一个词根下多个词都过了三道闸，且词根的意思和产品相斥 |
| 风险 | 小；同类的词还会一个个冒出来 | 大；可能挡掉以后的好长尾 |
| 谁定 | 人在行动页过 | 必须标「需人确认」，并列出会被一并挡掉的、出过单的词（有的话就不提） |

工作台现在出的否定动作都是精确否定和否定 ASIN。词组否定只作为「清单外建议」。

## 四、收割的规矩

- 条件五条全中才收：出单数过 `门槛.搜索词收割订单`；来源不是主干活动；还不是精确词；不是自家品牌词、不是 ASIN；在来源组没被否过。
- 成对：精确组加词，来源组精确否。只做前一半，两个组会抢同一个词；只做后一半，等于把出单词否掉了。
- 起价：这个词在来源组的实际 CPC；没有点击算不出时用 `调幅.收割词缺省起价`。上限是它的 CPC 天花板；点击不够算天花板时，用有转化的词的平均转化率做基准并标出来。
- 已经被换道否定处理过的词，不再重复出收割。
- 人驳回过其中任何一条，两条都不再提。

## 五、竞品品牌词

| 情况 | 去向 | 说明 |
|---|---|---|
| 出过单，ACOS ≤ 盈亏线 | 留 | 在赚钱 |
| 出过单，ACOS > 盈亏线 | 降价单独跑 | 出过单不能否；单独建精确词，出价按 目标 ACOS × 转化率 × 客单价，不低于 `调幅.竞品词单独跑最低竞价` |
| 零单，偶然概率还高 | 观察 | 样本不足 |
| 零单，偶然概率够低 | 否 | 在所有出现过它的活动里精确否 |
| 只在部分活动里否了，别处还在出单 | 交回运营判断 | 补否还是撤回，摆出两边的花费、订单、ACOS |

花费占比不到 `门槛.分拣表最小花费占比`、又只是观察或保留的竞品词不进分拣表，留在分组明细里。

竞品词要不要打，本质是任务问题：是为了抢单（看盈利），还是为了占位（看值不值）。任务没定时，只按盈亏线分拣，不谈策略。

## 六、相斥词根

相斥词根是「一出现就基本说明买家要的不是这个品」的词根。按六类整理：

| 类 | 例如（示意，各品类自己填） |
|---|---|
| 人群 | 产品给成人用，词里出现婴儿、宠物 |
| 材质 | 产品是硅胶的，词里出现木质、金属 |
| 颜色或款式 | 只做深色，词里出现指定的浅色 |
| 品牌 | 打不过、也不想打的别家品牌 |
| 功能 | 产品不带的功能，例如不防水却出现防水 |
| 场景 | 产品用在室内，词里出现户外、车载 |

整理的来源：跑偏和泛词里花费靠前的词；退货原因里「与描述不一致」对应的期待；人的产品知识。

用法：

- 作为新建活动时预先否定的候选。
- 作为 `分组规则.json` 的 `OFF` 的补充候选，由人加。
- 一个词根进相斥词库前，查一遍它下面有没有出过单的词。有，就不是相斥，是待观察。

## 七、拓词方向

- 三类泛入口：人群词（给谁用）、礼物词（买来送谁）、场景词（什么场合用）。
- 判断值不值得试：产品是不是真的能满足这个需求，而不是「竞品在这个词下出现过」。偶然曝光不等于相关。
- 试的方式：低出价、小预算，看能不能被收录、有没有点击和成交。目标是多拿入口，不是硬推排名。
- 关注近一两个月新长出来的需求，比关注长期大词更可能有空档。看趋势要取外部数据，先说清调用几次。
- 拓出来的词归 `测词拓词` 任务，完成情况由 `ads-campaign-task` 判断。
