# ads-launch · 新品期

新品期的广告是手段：花钱是为了把自然流量和自然订单带出来，不是为了当下赚钱。所以新品不能用成熟链接的尺子量。TACOS 可以高，但要有期限和边界；广告单占比高是正常的，但要看它在不在往下走。

本 skill 只在 `参数.json` 的 `产品阶段` 是 `新品期` 时作主；其余九个 skill 默认面对成熟链接。

共用规矩在 `../ads-shared/`：`分工与红线.md`（先读）、`公式与口径.md`、`输出格式.md`、`术语.md`。本 skill 的细则在 `references/规则.md`，输出模板在 `templates/输出.md`。

## 一、什么时候用，什么时候不用

用：

- 「新品刚上架，广告怎么起步」
- 「上架第三周了，现在该做什么」
- 「广告单占了九成，正常吗」
- 「这两周卖得比预期快很多，要不要接着加」
- 「新品现在能不能放量」
- 「货只够卖三周，补货还要一个月，还推不推」
- 「新品先打哪些词，大词要不要上」

不用：

- 产品阶段已经不是新品期：走成熟链接的那几个 skill。
- 新品的目标 TACOS、允许亏多少：`ads-profit-target`（这里引用它的结果，并补上期限和边界）。
- 新品某个指标为什么突然变了：`ads-diagnose`。
- 具体某条动作的出价数：`ads-bid-budget`。
- 多个规格谁当主推：`ads-variant-season`（这里只要求「主推不断货」）。

| `广告闭环/输出/动作清单.json` | 暂停广告产品、补挂广告产品、下调预算、查证、Listing 建议稿 | 库存相关动作 |
| `广告闭环/输出/广告产品调整表.csv` | 每个活动每个规格：可售、上周销量、可售周数、建议 | 哪些规格上的广告该收 |
| `分组规则.json` | `CORE`、`MOD`、`INTENT`、`OFF`、`COMP` | 词库分层的现成材料 |
| `口径.json` | `判定.退款率警戒`、`判定.退款率相对首周倍数`、`判定.到仓快只降预算的周数上限`、`判定.到仓中等的周数上限`；暂定键 `新品.阶段周数`、`新品.自然单超额比例`、`新品.测试预算倍数`、`新品.曝光观察天数`、`新品.广告单占比警戒`、`经营.主推库存冗余`、`经营.次推库存冗余`（读不到只说方向，不给数） | 判断时引用 |

页面对应：阶段在「设置」页；库存和退款的异常在「首页」和「原因」页；断货规格的广告动作在「行动 · 待你决定」。

拿不到时：

- 没跑过：让用户先跑一圈或运行 `python3 _脚本/weekly.py --dry-run`。还没上架、没有任何报表时，可以只做第四节第 6、7 步（词库分层和起步结构），标明「上架前方案，没有数据」。
- 不知道上架第几周：产物里没有这一项就问人，不从件数猜。
- 没有自然排名数据：这是常态。按第四节第 6 步的降级办法走，不下坑位结论。
- 没有目标自然单：自然单是否超额这一条写缺，请人给一个目标。
- 周度经营表不足四周：阶段判定只看已有的周，写明周数。
- 评论数、星级、访客数不在工作台里：体检里这几项问人，或写「缺，请到卖家后台看」。

## 三、脚本算什么，你做什么

| 脚本算 | 你做 |
|---|---|
| 逐周件数、广告费、TACOS、转化率、退款率 | 读成「阶梯在不在往上走」 |
| 广告归因销售额占比 | 读成广告单占比的走势；提醒口径偏宽时它是上限 |

| 算账里的阶段和阶段要求 | 补上期限和损失边界的追问 |
| — | 判定五阶段里的哪一段 |
| — | 判断节奏快慢 |
| — | 六项体检逐项给结论或写缺 |
| — | 词库分层与每层投法 |

## 四、判断步骤

1. **确认是新品，并拿到三样前提。** `产品阶段` 是 `新品期`。然后问三件硬前提，任何一件不成立，先停广告的加码，去补它：
   - 页面里该埋的词埋了没有（标题、要点、后台搜索词覆盖了核心词和主要属性词）；
   - 星级稳不稳（退款率和退货原因是能看到的侧面，`判定.退款率警戒`）；
   - 货会不会断（第 5 步）。
2. **判定在五阶段的哪一段。** 按上架周数对照 `新品.阶段周数`：破局 → 爬升 → 抢位 → 优化 → 稳定。`口径.json` 里读不到这个键时，不按周数判，只按表现判，并说明口径里还没有阶段周数。每一段的目标、看什么数、典型动作在 `references/规则.md` 第一节。周数和实际表现对不上时（周数到了抢位，数据还像破局），以表现为准，并指出落后了。
3. **判断节奏。** 两个方向都要看，细则见 `references/规则.md` 第二节：
   - 过快：广告单占比高于 `新品.广告单占比警戒` 还在升、转化率高得反常、单量大幅超过计划。后果是广告抢走了本该落到自然位的点击、点击成本被自己抬高、库存先耗尽。自然位的沉淀需要几周，急不来。
   - 过慢：到了该爬升的周数，访客和订单没有阶梯；或广告花不出去。回到前提和第 7 步的测试结构查原因。
4. **六项基础体检：能不能继续放量。** 逐项给「过、不过、缺」：
   - 产品过关（退款率、退货首因）；
   - 评论基础（工作台没有，问人）；
   - 价格和转化被接受（转化率逐周稳定或上升）；
   - 访客与订单阶梯增长（逐周件数；访客数工作台没有）；
   - 广告单占比在降、自然单占比在升（广告归因销售额占比的走势）；
   - 主推不断货（主推规格的可售周数对补货到仓周数）。
   六项全过才说「可以继续放量」。有不过的，先补那一项；有缺的，结论写「条件未核全」。
5. **库存和销量，谁服从谁。** 读 `库存`：
   - 货在途、到仓日改不了：推广节奏和销量目标服从库存。把目标销量压到货撑得住的水平，断货规格上的广告按清单里的动作收（到仓周数不超过 `判定.到仓快只降预算的周数上限` 只降预算，更慢就暂停并补挂同规格库存足的另一款）。
   - 货还能调：按销量目标倒推备货，主推、次推各留冗余（`经营.主推库存冗余`、`经营.次推库存冗余`）。
   - 到仓周数是这一步的关键输入。它是估的就说是估的，并指到清单里的「查证」动作。
6. **词库分层。** 每个词贴两个标签：相关性（决定自然位能到多高）和流量大小。分成几层，每层投法不同，细则在 `references/规则.md` 第三节：
   - 相关性最高、转化有把握的：重点投精准，是要沉淀自然位的词。
   - 相关但转化没把握的：保守出价试探。
   - 大词：单独一个活动，不和别的词混；新品期不锁首页首位。
   - 广泛：覆盖越窄出价越高；跑出来不相干的词多，就不打广泛。
   - 相斥词根：预先否定。
   **没有自然排名数据时的降级**：不说「目标坑位第几」，改用三个能看到的信号代替：这个词自己的转化率、它的订单数、整体广告单占比有没有在降。并写明「缺自然排名，坑位结论不下；要查得花钱，约几次调用」。
7. **起步测试怎么搭（破局段，或还没上架）。** 目的是拿到基准值：多少出价才有曝光、基准点击成本、点击率、转化率、获单成本。结构、预算、通过与不通过的信号、曝光起不来时的检查清单，见 `references/规则.md` 第四节。要点：固定竞价；自动投放只开紧密匹配；手动广泛只放一到三个最核心的词；预先否定相斥词根；日预算是预估获单成本的 `新品.测试预算倍数`，太小测不出结论。
8. **折扣。** 折扣和广告费是同一笔营销费用，合在一起算总获单成本。折扣太大，买家冲着价格来，不利于自然流量沉淀；太小，起不了势。折扣定多少是人的事，你把合并后的获单成本算给他看。
9. **补上期限和边界。** 新品的 TACOS 可以高于目标甚至高过定价毛利率，但必须有两个数：亏到哪一天为止，最多亏多少钱。人没给就问；给了就写进结论，并算出照现在的速度还能撑几周。
10. **说清什么时候毕业。** 稳定段的信号出现（广告单占比降下来并稳住、预算开始向低 ACOS 的流量倾斜、TACOS 回到目标附近）：建议人把 `产品阶段` 改成放量期或维稳期，之后走成熟链接那条线，从 `ads-profit-target` 重新定目标开始。

## 五、常见情形

**情形 1：上架第二周，广告单占比接近全部**

- 读到：`四周.广告归因销售额占比` 很高；周数在破局段。
- 判断：这一段是正常的。要看的是之后几周它降不降。
- 怎么答：说明新品头几周订单本来就靠广告；这个数是偏宽口径的上限；约定从哪一周开始它该往下走。
- 不要：按成熟链接的口气说「广告依赖过重」。

**情形 2：卖得比计划快，库存撑不到补货**

- 读到：逐周件数快速上升；主力规格可售周数小于 `补货到仓周数`；清单里有暂停或降预算的动作。
- 判断：货在途改不了时，销量目标服从库存。
- 怎么答：先说库存；解释清单里的动作（到仓快降预算、到仓慢暂停并补挂）；提醒补挂的款转化没验证过；到仓日是估的就指到「查证」。
- 不要：趁势建议加预算。

**情形 3：周数到了抢位段，数据还没有台阶**

- 读到：上架周数对应抢位；逐周件数基本走平。
- 判断：表现落后于周数。以表现为准。
- 怎么答：实际阶段写爬升甚至破局；回头查三样前提和起步结构；不靠加钱追进度。
- 不要：按周数照搬抢位段的动作去拉出价。

**情形 4：用户问「核心词现在排第几」**

- 读到：工作台没有自然排名数据。
- 判断：答不了位置。
- 怎么答：说明缺排名；用替代信号回答能回答的部分（广告单占比走势、这个词的转化率和订单）；要真实排名得花钱查，说清查哪几个词、约几次调用。
- 不要：从广告数据推一个名次出来。

**情形 5：还没上架，想先把方案定下来**

- 读到：没有任何报表。
- 判断：只能出上架前方案。
- 怎么答：做词库分层和起步测试结构；预算用预估获单成本乘倍数，转化率给低、中、高三档假设；标明「没有数据，上架后按实际修正」。
- 不要：给出确定的出价和预期单量。

**情形 6：广告单占比降下来并稳住了，TACOS 回到目标附近**

- 读到：逐周走势；`算账.判定` 在目标内或接近。
- 判断：稳定段的信号。
- 怎么答：建议人把 `产品阶段` 改成放量期或维稳期；说明改了之后目标要重新定，从 `ads-profit-target` 开始。
- 不要：自己当它已经是成熟链接，换一套尺子。

## 六、输出

- 按 `../ads-shared/输出格式.md`，加 `templates/输出.md` 的阶段卡、节奏表、体检表、词库分层表。
- 只在对话里回答，不写 `广告闭环/输出/AI补位.json`。
- 动作引用清单编号，指到「行动 · 待你决定」；新建活动、调折扣、改 Listing 都是「清单外建议」，带三问。

## 七、不许做的

- 不用成熟链接的标准说新品「ACOS 太高」「广告占比太高」。说占比要看走势。
- 不把周数边界、冗余比例、超额比例这类数写死或凭印象说，一律读 `口径.json`；读不到就说缺。
- 不拿别的产品的推新数字当这个产品的目标。
- 不在没有自然排名数据时说「已经上首页」「排名到了第几」。
- 不在货撑不住时建议加预算、提竞价。
- 不建议新品期锁首页首位。
- 不替人定折扣、定允许亏多少。
- 不在六项体检没核全时说「可以放量」。

## 八、自查三句

1. 我判定的阶段，依据是上架周数加实际表现，还是只看了周数？
2. 六项体检里工作台没有数据的那几项，我是写了「缺」，还是默默当成了「过」？
3. 我谈到自然位时，手上真的有排名数据吗？没有的话有没有按降级办法说？
