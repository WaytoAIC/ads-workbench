阈值都引用 `口径.json` 的键，含义见 `../ads-shared/公式与口径.md` 第八、九节；公式见同一文件第五节（路径都从本 skill 目录算起）。

## 一、分档表

近窗口的表现决定落在哪一档。从上往下看，先命中的算数。

### 关键词

| 条件 | 动作类型 | 幅度 |
|---|---|---|
| 零单，点击 ≥ `门槛.关键词零单暂停点击` | 暂停关键词 | — |
| ACOS 高于盈亏线，点击 ≥ `门槛.关键词降竞价点击` | 关键词降竞价 | 降 `调幅.竞价单次下调`，不低于 `调幅.最低竞价` |
| ACOS 低于 目标 ACOS × `判定.提竞价ACOS相对目标`，订单 ≥ `门槛.提竞价订单`，活动无库存风险 | 关键词提竞价 | 提 `调幅.竞价单次上调` |
| 其余 | 不动 | — |

### 商品定位（ASIN、类目）与自动投放的四个组

| 条件 | 动作类型 | 幅度 |
|---|---|---|
| 零单，点击 ≥ `门槛.商品定位零单暂停点击`（自动组用 `门槛.自动投放组零单关闭点击`） | 暂停 ASIN 定位、暂停 类目定位、关闭自动投放组 | — |
| ACOS 高于盈亏线，点击 ≥ `门槛.商品定位降竞价点击` | 对应的降竞价 | 同上 |
| ACOS 远低于目标，订单够，活动无库存风险 | 对应的提竞价 | 同上 |

### 结构压价（不看表现，看层次）

| 条件 | 动作类型 | 新值 |
|---|---|---|
| 词组活动里的词，出价高于精确组中位价 × `调幅.结构降价触发比例` | 降竞价 | 精确中位价 × `调幅.词组竞价压到精确的比例` |
| 广泛活动里的词，同上 | 降竞价 | 精确中位价 × `调幅.广泛竞价压到精确的比例` |
| 非主干活动里，出价高于本组中位价 × `调幅.非主干高于组内中位的触发比例` 的词 | 降竞价 | 本组中位价 |

### 活动层

| 条件 | 动作类型 | 新值 |
|---|---|---|
| 近 7 天日均花费 ≥ 预算 × `判定.预算吃紧比例`，ACOS ≤ 目标，活动无库存风险 | 预算上调 | 加 `调幅.预算单次上调` |
| 组内有规格一周内断货，补货到仓周数不超过 `判定.到仓快只降预算的周数上限` | 下调预算 | 降 `调幅.预算单次下调`，到仓后恢复 |
| 活动 ACOS 高于盈亏线，点击 ≥ `门槛.活动级判断点击`，策略是「提高和降低」 | 改竞价策略 | 改为「只降低」 |
| 同上，且有广告组默认竞价 | 下调默认竞价 | 降 `调幅.竞价单次下调` |

两条通用规矩：

- 一个对象一轮只动一次。
- 取整到分时往安全的一侧取：降价向上取整，提价向下取整，保证实际调幅不越线。
- 验证器的两条硬线：竞价单次调幅不超过 `调幅.竞价单次调幅上限`，预算单次调整不超过 `调幅.预算单次调整上限`。越线整轮作废。

## 二、不是出价问题的三种情况

| 现象 | 实际是什么 | 该怎么说 |
|---|---|---|
| 日曝光低于 `判定.日曝光过低`，实际 CPC 还没到天花板 | 出价不够 | 可以加一步，加完看曝光 |
| 日曝光低，出价已到天花板 | 这个词本身流量小 | 标「词本身流量小」，不再加价；要量得去找别的词 |
| 点击率低于 `判定.点击率过低`，ACOS 高 | Listing 吸引不了点击 | 转 `ads-diagnose`；这时降价只是少亏，加价是多亏 |
| 转化率突然掉，同期主力规格断货 | 库存 | 先收断货规格上的广告 |
| CPC 稳，转化率稳，ACOS 仍高于目标 | 目标高于这个词的实际能力，或客单价低 | 降到天花板为止；再低就会丢量，说明取舍，让人定 |

## 三、调价的节奏

### 加价：走走停停

1. 曝光、点击不够 → 加一步。
2. 加完等一个短观察期。
3. 有了点击和订单 → 停，观察转化和成本，不因为「还能更多」连着加。
4. 仍然没有曝光 → 再加一步，直到天花板。到了天花板还没有，按「词本身流量小」处理。

### 先横后纵

- 横：让更多能成单的词拿到曝光（覆盖面）。
- 纵：把单个词的出价往上拉（位置）。
- 顺序是先横后纵。很多词都还没跑出数据时就集中抬一个词的价，容易把钱压在一个不确定的词上。

### 降价：按周小步

1. 每次降一档，一周一次。
2. 每次降完看三个数：这个对象的订单、CPC、所在活动的利润贡献。
3. 订单没有明显减少 → 下周继续。订单明显减少 → 停在上一档。
4. 降价后广告位可能后移。位置是手段，判断标准仍是订单、成本、利润。
5. 降出价后花费不一定同比例下降：需求在涨、转化在变好时，更低的价格也可能买到更多流量。

### 冷静期

- 大改之后 `复盘.大改冷静期天数` 之内，不再动同一个对象，也不拿这几天的数下结论。
- 「大改」指：暂停或启用、调幅用满上限、改竞价策略、预算调整、新建或拆分活动。

## 四、广告位（有报表时才用；报表可以从广告接口拉，见 `数据格式.md`）

### 实际出价

实际出价 ≈ 基础竞价 × 竞价策略的浮动 ×（1 + 该位置的加价）。

| 竞价策略 | 浮动 |
|---|---|
| 固定竞价 | 平台不调 |
| 只降低 | 转化可能性低时往下调 |
| 提高和降低 | 转化可能性高时往上调，搜索顶部上浮更多 |

### 三个位置

| 位置 | 特点 |
|---|---|
| 搜索顶部 | 位置少、最贵、对排名和占位有价值，获单成本风险高 |
| 搜索其余位置 | 价格居中，覆盖面广 |
| 商品页面 | 位置多、通常便宜，适合低成本拿单或占别家页面 |

### 用曝光比判断出价落在哪一档

没加搜索顶部加价、用固定或只降低时，商品页曝光通常是搜索结果页（顶部加其余）曝光的若干倍，常见区间见 `判定.商品页与搜索页曝光比区间`。

| 档 | 现象 | 说明 |
|---|---|---|
| 一 | 商品页曝光远超区间上沿，搜索结果页几乎没有 | 出价只够进商品页 |
| 二 | 搜索其余位置有量，比值在区间内，顶部很少 | 正常的搜索结果页出价 |
| 三 | 顶部时有时无 | 出价在顶部的门槛附近，不稳 |
| 四 | 顶部占了主要份额 | 稳定在顶部 |

这是帮助判断的经验区间，不是定律。

### 加价值不值

- 把每个位置的花费、订单、ACOS 分开看。加了价的位置 ACOS 在目标内，或它承担的是人确认过的推自然位任务 → 加价站得住。
- 加了价的位置近 14 天点击过 `门槛.广告位判断点击`，却 0 单或 ACOS 高于盈亏线 → 清单里出「下调广告位加价」。幅度脚本已经算好：折到这个位置的出价上，一次最多降 `调幅.竞价单次下调`，降到 0 为止。加价已经是 0 还亏的，该降的是竞价本身，不归这一条。
- 某个位置 ACOS 不到目标的 `判定.提竞价ACOS相对目标`、订单过 `门槛.提竞价订单`，活动这轮又没在降预算 → 清单里出「上调广告位加价」，一次提 `调幅.竞价单次上调`，最高到 `调幅.广告位加价上限`。
- 它承担的是人确认过的推自然位任务时，「下调」那条可以驳回：写明理由，下一圈不再提。
- 清单里没有、但你认为值得试的加价，作为「清单外建议」提出，带三问，不给数。

### 失真提醒

下面的活动，广告位的数不能直接读：

- 自动投放的多个组混在一个活动里；
- 一个活动里词根差别很大；
- 预算每天很早就花完（看到的只是上午的分布）；
- 链接权重低、投放本身受限。

## 五、预算的补充规则

- 单品日预算是全部活动合计的边界，由 `ads-profit-target` 解释。这里只判断单个活动的加减。
- 活动上填的平均日预算不是当天硬上限，单日实际花费可能高于它。
- 加预算的顺序：纯利型达标的 → 收割达标的 → 其余。手段型任务未达标的不加。
- 出价有冗余的信号：实际 CPC 明显低于出价；或预算很早花完而 CPC 还有下降空间。这时先降出价，比直接降预算好，同样的预算能买到更多点击。
- 销售额明显变化后，先让 `ads-profit-target` 重算边界，再谈各活动的预算。

## 六、任务和动作的搭配

| 任务 | 高于盈亏线时 | 远低于目标时 |
|---|---|---|
| 纯利型 | 降；降不回线内就重新定任务 | 提、加预算，逐步放大 |
| 收割 | 降到天花板 | 提 |
| 推自然位 | 不直接降；看观察期和自然位有没有改善，交 `ads-campaign-task` | 说明不需要这么高的成本也能维持，可以试着降 |
| 测词拓词 | 降或收窄；它不该是花费大户 | 保持低价 |
| 防守 | 查是否混进非品牌词 | 保持 |
| 未判定 | 只解释脚本的动作，不追加 | 同左 |
