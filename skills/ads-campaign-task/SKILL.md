# ads-campaign-task · 广告任务盘点与结构体检

同一条广告，放在不同任务下，结论可以相反：推排名的广告 ACOS 高一点是计划内的，买利润的广告 ACOS 高就是亏。所以在谈出价和否词之前，先给每个活动一个任务，再问它完成了没有。

共用规矩在 `../ads-shared/`：`分工与红线.md`（先读）、`公式与口径.md`、`输出格式.md`、`术语.md`。本 skill 的细则在 `references/规则.md`，输出模板在 `templates/输出.md`。

## 一、什么时候用，什么时候不用

用：

- 「把活动过一遍，哪些该留哪些该收」
- 「自然位都在前几名了，这个词的广告还要不要打」
- 「哪些广告是在白花钱」
- 「有没有能直接赚钱、可以多投的广告」
- 「十几个活动互相抢词，帮我看看结构」
- 「这个活动 ACOS 很高，但我是拿它推排名的，算不算有问题」

不用：

- 还不知道整体卡在哪：先 `ads-diagnose`。
- 具体某个词出价多少、预算加多少：`ads-bid-budget`。这里判断「该不该动」，那里定「动多少」。
- 搜索词层面的否定和收割：`ads-search-term`。这里只看到活动和投放这一层的重复与倒挂。
- 新品期的测试结构怎么搭：`ads-launch`。
- 主推、次推各自承接哪些词：`ads-variant-season`。

## 二、先读什么

| 读什么 | 看哪些键 | 用来做什么 |
|---|---|---|
| `广告闭环/输出/经营.json` | `任务`（每项的 `活动`、`建议任务`、`依据`、`完成情况`、`完成依据`、`标记`、`人定任务`、`缺`）；`算账.目标TACOS`；`拆解.核心限制` | 脚本给的任务建议和完成情况 |
| `广告闭环/输入/活动任务.json`；`任务` 里每项的 `人定任务` | 人在「广告活动」页确认过的任务（工作台从状态库写出来） | **人确认的优先于一切** |
| `广告闭环/输出/AI补位.json` | `任务标签`（每个活动的 `任务`、`理由`） | 上一次你起草了什么 |
| `广告闭环/输出/数字.json` | `活动表`（两个窗口的花费、点击、订单、销售额、ACOS）、`活动`（个数、名义日预算合计、竞价区间、已有否词）、`同词多活动`、`头部词`、`头部词分道`、`精确组占头部词花费` | 表现与结构事实 |
| `参数.json` | `精确活动`、`词组活动`、`广泛活动`、`主干活动`、`目标ACOS`、`产品阶段` | 人对活动分工的说明 |
| `广告闭环/输出/动作清单.json` | 类型为降竞价（结构压价）、换道否定、交回运营判断、预算上调的条目 | 结构问题已经出了哪些动作 |
| `广告闭环/输出/读回状态.json` | `被驳回的动作` 及理由 | 哪些结构是人有意为之 |
| `口径.json` | `经营.纯利型订单门槛`、`门槛.活动级判断点击`、`门槛.搜索词收割订单`、`门槛.同词多活动的活动数`、`判定.同词多活动花费占比警戒`、`判定.预算吃紧比例`、`调幅.词组竞价压到精确的比例`、`调幅.广泛竞价压到精确的比例`；待补键 `经营.推自然位观察周数`（读不到只说方向） | 判断时引用 |

活动由什么构成（广告组、广告产品、关键词或定位、否定、竞价策略、广告位加价）由 `_脚本/structure.py` 整理，在「广告活动」页逐个展开；人在同一页确认或修改每个活动的任务。

拿不到时：

- 没有 `广告闭环/输出/经营.json` 或 `任务` 为空：让用户先跑一圈或运行 `python3 _脚本/weekly.py --dry-run`。只有 `广告闭环/输出/数字.json` 时可以做结构体检（第四节第 7 步），任务一律写 `未判定`。
- 没给关键词竞价表：看不出竞价倒挂，写缺，指到 `数据格式.md`。
- 没给否定词表：看不出否词有没有否干净，重复投放的结论要打折。
- 没有自然排名：推自然位的任务完成情况一律 `看不出`。
- 没有 `广告闭环/输入/活动任务.json`：还没有人确认过任何任务。把 `任务` 里脚本的建议当草稿，并请人到「广告活动」页确认。

## 三、脚本算什么，你做什么

| 脚本算 | 你做 |
|---|---|
| 每个活动两个窗口的花费、订单、ACOS | 只读 |
| 建议任务、依据、完成情况、完成依据、标记 | 检查依据够不够；你认为不够的，在任务标签草稿里写 `未判定` 并说明缺什么（脚本的建议和完成情况不改） |
| 同词多活动的词数、花费、占比 | 判断是结构问题还是有意为之（看驳回理由） |
| 头部词分道、精确组占比 | 说明精确组有没有起到收割的作用 |
| 结构压价、换道否定等动作 | 解释为什么出、引用编号 |
| — | 起草任务标签（六类之一）和理由 |
| — | 给每个活动一句「接下来怎么处理」 |

## 四、判断步骤

1. **先读人确认过的。** 人在「广告活动」页确认过任务的活动，任务以人为准（`任务` 里的 `人定任务`），完成情况脚本会按人定的任务来判。人确认的任务和表现看起来矛盾时（例如确认为纯利型但 ACOS 高过目标 TACOS），不改任务，在「AI 判断」里指出矛盾，请人复核。
2. **没确认的，按线索定任务，不按 ACOS 定。** 线索的先后：
   - `参数.json` 里人指定的精确、词组、广泛活动及主干活动；
   - 活动的构成：投放方式（自动还是手动）、匹配类型、投的是词还是商品、投的是不是自家品牌词；
   - 活动名里人留下的说明；
   - 脚本的 `建议任务` 和 `依据`。
   表现数据只用来判断任务完成没有，不用来反推任务是什么。线索不够就是 `未判定`，写清「缺哪条线索，请在广告活动页确认」。脚本的建议本身也是按结构线索给的（自动投放 → 测词拓词；指定的精确活动 → 收割；含自家品牌词 → 防守；盈亏线内的词组、广泛主干 → 推自然位），只有 `纯利型` 是按表现给的候选，见第 6 步。
3. **六选一。** `纯利型`、`推自然位`、`测词拓词`、`收割`、`防守`、`未判定`。每一类的认定线索和完成标准在 `references/规则.md` 第一节。同时标出它是手段还是目的。
4. **读完成情况，三选一。** `达标`、`未达标`、`看不出`，以脚本的 `完成情况` 和 `完成依据` 为准，你不改它：
   - 纯利型：看近 7 天的 ACOS 是否仍低于目标 TACOS。
   - 测词拓词：看近 14 天有没有产出订单过 `门槛.搜索词收割订单` 的搜索词。
   - 收割、防守、推自然位：脚本只到活动层，一律 `看不出`，并在 `缺` 里写明要什么数据（精确词各自的表现、品牌词占位、核心词自然排名）。
   - 底线：不管什么任务，ACOS 超盈亏线且点击过了 `门槛.活动级判断点击`，或零单且点击过了这个门槛，脚本一律判 `未达标` 并标「任务没完成」。推自然位可以暂时高于目标 ACOS；但样本够了还在盈亏线之上，就需要人明确说继续到什么时候、最多花多少。
   - 脚本写 `看不出` 的，你可以在「AI 判断」里补充看到的线索（例如精确组接住了多少头部词花费、这个词推了几周、是否已超过 `经营.推自然位观察周数`），但不把它改写成达标或未达标。
5. **按「任务 × 完成情况」给处理意见。** 对照表在 `references/规则.md` 第二节。几条要紧的：
   - 手段型未达标、观察期已过：建议撤回或把预算转给别的任务。这类广告最常见的问题是「舍不得那几单」。
   - 手段型达标：任务完成了，可以逐步减，不是继续加。
   - 目的型达标：自然位再高也不是停掉它的理由，它本身在赚钱。
   - 目的型未达标：先交给 `ads-bid-budget` 看能不能把成本降到线内，降不下来再谈收。
   - 减广告要分步，每一步后看自然单和总利润，不一次全关。减了以后总单量可能略降，这不等于做错了，要看利润。
6. **看纯利型候选。** 脚本把「ACOS 低于 `算账.目标TACOS` 且订单过 `经营.纯利型订单门槛`」的活动标为「纯利型候选」。用目标 TACOS 这条线，是按最保守的算法（假设新增的广告一个自然单都不带）。你再核一条脚本没看的：它是不是挂在库存有风险的规格上。候选要人确认后才算纯利型；同时提醒三件事（细则见 `references/规则.md` 第三节）：效率好和能放大是两回事；受众类、展示类广告的归因有水分，要对照整体生意有没有真的多出来；新结构先做出一条，稳了再复制。
7. **结构体检，四项。** 每项给事实和判定，细则在 `references/规则.md` 第四节：
   - 重复投放：同一个词被几个活动同时买（`同词多活动`），占花费多少。
   - 竞价倒挂：精确、词组、广泛的竞价是不是分了层，还是几乎一个价。
   - 头部词去向：头部词的花费有多少落在精确组，多少散在别处。
   - 活动构成：一个活动里是不是混了任务不同的词或多个广告组，导致预算和广告位看不清。
   已有对应动作的引用编号；人驳回过的（理由是有意为之）不再当问题提。
8. **看预算和任务是否相称。** 预算吃紧（`判定.预算吃紧比例`）的活动如果是目的型达标的，标「预算吃紧」，交给 `ads-bid-budget`；如果是手段型未达标的，吃紧不是加预算的理由。
9. **汇总成一句话。** 这个产品的广告费，按任务分，大致各占多少；其中有多少落在未达标和未判定上。这句话是 `ads-path-decision` 选路径时要用的。

## 五、常见情形

**情形 1：精确活动 ACOS 高于目标，人确认过它在推自然位，没有排名数据**

- 读到：`任务` 里这个活动的 `人定任务` 是推自然位；工作台没有自然排名。
- 判断：任务以人为准；完成情况没法判断。
- 怎么答：完成情况写 `看不出`；说明已经推了几周、观察期到没到；问要不要花钱查排名（查哪几个词、约几次调用）。
- 不要：因为 ACOS 高就说它未达标，或因为它在出单就说达标。

**情形 2：自动投放活动 ACOS 很低，但一周只有几单**

- 读到：投放方式是自动；ACOS 低于目标 TACOS；订单没过 `经营.纯利型订单门槛`。
- 判断：按结构它是测词拓词。ACOS 低不改变它的任务。规模不够，也不算纯利型候选。
- 怎么答：任务 `测词拓词`；把出单的词交给 `ads-search-term` 看能不能收割；说明「效率好但量小，不算纯利型」。
- 不要：贴上纯利型然后建议加预算。

**情形 3：一个活动里一半是自家品牌词，一半是品类大词**

- 读到：「广告活动」页这个活动的关键词构成。
- 判断：防守和推词混在一起，预算和表现都读不清。
- 怎么答：任务 `未判定`；结构体检记「活动构成：混任务」；建议拆成两个后分别定任务（清单外建议，带三问）。
- 不要：按花费多的那一半硬定一个任务。

**情形 4：同一个词被四个活动同时买，上一圈人驳回了换道否定**

- 读到：`同词多活动` 占比高；读回状态里对应动作被驳回，理由是有意为之。
- 判断：人已经解释过，这不是待解决的问题。
- 怎么答：体检表里照列事实，判定写「人确认为有意为之」，不再提动作。
- 不要：换个说法再建议一次。

**情形 5：「这个词自然位已经第一了，广告还打不打」**

- 读到：这个词所在活动的任务。
- 判断：答案取决于任务，不取决于自然位。
- 怎么答：手段型且目标已达到 → 可以分步减，每步看自然单；目的型且在赚钱 → 不因为自然位高就停。任务没定 → 先请人确认。
- 不要：只凭「自然位高」给结论。

**情形 6：十几个活动，大多数是未判定**

- 读到：`任务` 里多数 `建议任务` 是未判定，人确认过的很少。
- 判断：这时候逐个给处理意见没有基础。
- 怎么答：按花费排，请人先确认最大的三个；其余只做结构体检。说明任务确认前不出收或放的建议。
- 不要：为了把表填满，给每个活动猜一个任务。

## 六、输出

- 按 `../ads-shared/输出格式.md`，加 `templates/输出.md` 的任务盘点表和结构体检表。
- 活动多于十个：表里列花费最高的十个，其余按任务汇总成一行。
- 平时只在对话里回答。每周一圈时，你给出的任务标签由 `_脚本/llm.py` 写进 `广告闭环/输出/AI补位.json` 的 `任务标签`，每个活动一个 `任务`（六类之一）和一句 `理由`。不在六类里的值会被丢弃。
- 你起草的是标签草稿。人在「广告活动」页确认后才算数，确认这一步你不能代做。

## 七、不许做的

- 不从 ACOS 反推任务。
- 不改人确认过的任务，不改脚本给的完成情况。
- 不在没有排名数据时说推自然位「有效」或「无效」。
- 不因为自然位高就建议停掉在赚钱的广告；也不因为「位置好看」「是视频广告」给长期亏损的广告找理由。
- 不建议一次性关掉一批广告。
- 不把人驳回过、说明是有意为之的结构再当问题提。
- 不把纯利型候选说成「可以放心放量」。能不能放大要试，试多少由人定。

## 八、自查三句

1. 每个活动的任务，我说得出是凭哪条线索定的吗？有没有哪一个其实是看 ACOS 猜的？
2. 完成情况为「达标」「未达标」的，判断用的数据真的有吗？没有的是不是写了「看不出」？
3. 我有没有把人确认过的任务和人驳回过的理由先读一遍？
